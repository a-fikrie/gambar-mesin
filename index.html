04 · Hasil akhir

Keluaran dan pengumpulan

Siapkan set gambar kerja dengan informasi yang memadai untuk menggambarkan bentuk dan fitur setiap komponen.

Dokumen yang dikumpulkan

  • Gambar detail: Base Plate, Bracket, Wheel, dan Axle.
  • Gambar rakitan beserta identifikasi komponen.
  • Pandangan ortogonal dan potongan yang relevan.
  • Dimensi, toleransi, simbol permukaan, dan etiket.
  • File sumber CAD serta hasil PDF A3 sesuai ketentuan dosen.

Petunjuk teknis

Gunakan satuan milimeter, atur layer untuk jenis garis, sertakan simbol proyeksi dan skala pada etiket, serta periksa hasil cetak A3 sebelum pengumpulan.

Keamanan soal: jangan menempatkan kunci jawaban atau file dosen pada repository publik. Pengumpulan melalui formulir/kelas ditentukan kemudian oleh pengampu.
